模块五：性能优化

← 返回讲解文档

性能参数调节

maximumScreenSpaceError 16
maximumMemoryUsage (MB) 512
resolutionScale 1.0
⚠ SSE 越小精度越高但性能开销越大；移动端建议 ≥ 24。

傻瓜式优化清单

  1. 开启 requestRenderMode ← 静态场景必开
  2. 调大 maximumScreenSpaceError 至 16~32
  3. 关闭阴影 viewer.shadows = false
  4. 关闭雾效 viewer.scene.fog.enabled = false
  5. 降低分辨率 resolutionScale = 0.75
  6. Entity > 100 → 改用 Primitive
  7. 限制 maximumMemoryUsage 防内存溢出
  8. 使用 LOD（3D Tiles 自带多级细节）
