数据类型全景图

数据类型常见格式加载方式 / API适用场景

Module 02

Entity API

增删改查流程

viewer.entities.add()
→
entities.getById(id)
→
修改 entity.position / 属性
→
entities.remove(entity)

绑定业务属性

通过 entity.properties 挂载自定义键值对（如 ID、状态、类型），拾取时可直接读取，无需额外数据结构映射。

样式配置

支持 point / billboard / label / polygon 等可视化样式，均支持 heightReference 贴地设置。

飞行定位

viewer.zoomTo(entity) 或 viewer.flyTo(entity) 快速定位到目标实体，支持传入 offset 控制视角。

选型决策树：Entity vs Primitive

问：你的场景中需要渲染多少个同类对象？
≤ 100 个
→ 使用 Entity API
代码简洁、支持属性绑定、自动管理生命周期
> 100 个
→ 改用 Primitive API
直接操作 GPU 缓冲、批量渲染、性能提升 10x+
⛔
性能红线：Entity 数量超过 100 后帧率将显著下降。如需展示上千个标注点，务必使用 PointPrimitiveCollection 或 BillboardCollection。

属性查询

点击拾取流程

→

→
类型判断
Entity or 3DTileFeature?
→
UI 反馈
弹窗 / 高亮 / 控制台

拾取分支判断

Entity 拾取

判断条件：picked.id instanceof Cesium.Entity

读取属性：entity.properties.getValue()

场景：点标注、自定义图标、路径对象

3D Tiles 要素拾取

判断条件：picked instanceof Cesium3DTileFeature

读取属性：feature.getProperty(name)

场景：倾斜摄影建筑、BIM 构件、管线

空白区域

拾取方式：scene.pickPosition()

转换坐标：Cartographic.fromCartesian()

场景：获取地理坐标、高程查询

⚠
大数据建议：前端拾取只取对象 ID，详细信息通过后端接口查询返回，避免前端内存暴涨。切勿将全量业务数据都挂载到 entity.properties 上。

Module 04

调试与体检

核心调试工具

Cesium Inspector

通过 viewer.extend(Cesium.viewerCesium3DTilesInspectorMixin) 开启，可查看 3D Tiles 瓦片加载状态、包围盒、LOD 层级、内存占用。

浏览器 Network 面板

过滤 b3dm / i3dm / terrain 等关键字，观察请求数、响应时间、是否返回 404/CORS 错误。

Console 调试

使用 viewer.entities.values 遍历实体列表；viewer.scene.primitives 查看 Primitive 集合；viewer.camera 获取相机位姿。

常见症状自查表

症状可能原因排查方向
白屏WebGL 上下文丢失检查 GPU 驱动 / 浏览器硬件加速开关
黑屏（无底图）影像服务未响应或 Token 无效Network 面板检查影像 URL 返回状态
模型悬空未设置 heightReference改为 CLAMP_TO_GROUND 或调整高度偏移
模型沉入地下地形精度不匹配检查 modelMatrix 或 heightOffset
跨域错误（CORS）资源服务器未配置 CORS 头服务端添加 Access-Control-Allow-Origin
瓦片闪烁 / 加载慢SSE 设置过小 / 网络瓶颈增大 maximumScreenSpaceError 值
帧率极低Entity 过多 / 未启用按需渲染改用 Primitive + requestRenderMode
401 UnauthorizedIon Token 过期或权限不足前往 ion.cesium.com 重新生成

SSE 参数说明

参数含义默认值调优建议
maximumScreenSpaceError屏幕空间误差阈值（像素）16值越大加载越粗略但越快；移动端建议 24~32
maximumMemoryUsage3D Tiles 最大内存占用（MB）512低端设备限制到 256，防止 OOM
resolutionScale渲染分辨率缩放1.0设为 0.75 可降低 GPU 压力，牺牲清晰度

傻瓜式优化清单

1. 开启按需渲染

requestRenderMode = true
静态场景下 GPU 利用率可降至 5% 以下。必须配合 maximumRenderTimeChange 使用。

2. 调大 SSE

maximumScreenSpaceError = 24
减少同时加载的高精度瓦片数，帧率立竿见影。

3. 关闭特效

关闭 shadows、fog、FXAA，每项可释放 5~15% 的 GPU 开销。

4. 降低分辨率

resolutionScale = 0.75
渲染像素减少 ~44%，适用于低端显卡或 4K 屏。

5. Entity → Primitive

超过 100 个同类对象，改用 PointPrimitiveCollection / BillboardCollection，性能提升 10x。

6. 限制内存

maximumMemoryUsage = 256
防止低端设备因 3D Tiles 缓存过大导致 OOM 崩溃。
