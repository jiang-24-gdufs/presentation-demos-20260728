GIS 常用坐标系（EPSG）

EPSG名称说明
4326 WGS 84 GPS 全球标准，经纬度，Cesium 默认
3857 Web Mercator Web 地图投影（Google/OSM/天地图），单位：米。正方形瓦片，高纬度变形大
4490 CGCS2000 地理 中国国家大地坐标系，经纬度。天地图、自然资源部标准
4548 CGCS2000 投影 CGCS2000 高斯-克吕格投影，单位：米。国土测绘常用

超图 iDesktop / iServer

iDesktop数据制作时设定坐标系，常用 CGCS2000 (4490/4548) 或 WGS84 (4326)
iServer发布服务时可设置动态投影，REST 接口返回的坐标默认与数据源一致
Cesium 加载内部统一转为 WGS84 + Cartesian3，CGCS2000 与 WGS84 差异 < 1cm 可直接用

核心转换 API

经纬度→笛卡尔Cartesian3.fromDegrees()
笛卡尔→经纬度Cartographic.fromCartesian()
弧度↔角度Math.toDegrees() / toRadians()
屏幕→世界scene.pickPosition()
世界→屏幕SceneTransforms.wgs84ToWindowCoordinates()
⚠ fromDegrees 参数顺序：(经度, 纬度, 高度)，不是 (纬度, 经度)！
💡 为什么坐标系这么多？
地球不是完美球体 → 不同地区采用不同椭球和投影 → 各国/各行业需要各自精度最优的坐标系。Web 端统一用 4326 + 3857，Cesium 内部全部基于 WGS84。
